# Speaking Brot browser components

The default browser voice uses unchanged trained weights. Two optional warm-voice derivatives reduce weight storage precision to float16 or per-channel int8, keeping the architecture and float32 activations. No replacement model was trained or distilled. Components are served from this folder. No third-party CDN or speech service is required.

* **Piper voices**: [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices), northern_english_male medium and optional alba medium. Original model cards are in `models/`. Northern English training data: [OpenSLR 83](https://www.openslr.org/83/), CC BY-SA 4.0 International. Alba data: [University of Edinburgh](https://datashare.ed.ac.uk/handle/10283/3270), CC BY 4.0. Model bytes are copied unchanged from the locally installed originals; the asset manifest records their hashes.
* **ONNX Runtime Web 1.22.0**: [Microsoft source and licence](https://github.com/microsoft/onnxruntime/tree/v1.22.0). MIT; `vendor/ort/LICENSE`. Only the WASM inference loader and its matching single binary are included. Uses one thread, without SharedArrayBuffer or special isolation headers.
* **Piper phonemizer WASM 1.0.0**: [diffusion-studio/piper-wasm](https://github.com/diffusion-studio/piper-wasm), built from [wide-video/piper-wasm instructions](https://github.com/wide-video/piper-wasm) and [wide-video/piper-phonemize](https://github.com/wide-video/piper-phonemize). The npm wrapper declares MIT. Its compiled **eSpeak NG** component is GPLv3; see `vendor/phonemizer/ESPEAK-LICENSE` and [eSpeak source](https://github.com/rhasspy/espeak-ng). `trim_phonemizer.py` in the experiment records the English-only data selection, rebuilt offsets and ESM export; the WASM engine bytecode is unchanged. Other languages and their dictionaries have been removed.
* **WORLD**: [Masanori Morise and contributors](https://github.com/mmorise/World), modified BSD licence in `vendor/world/LICENSE`. Source snapshot and the small ABI wrapper/build recipe are preserved in `investigation/speaking_brot_browser_20261016/`. Only DIO, StoneMask, CheapTrick, D4C, synthesis and supporting FFT/common functions are compiled; no command-line or audio I/O tools are included.
* **SonicSafe**: pinned project output processing, copied without changes from Sonic's original. The main pipeline fills buffers before assignment for Firefox, then applies this chain and exports the same PCM used by playback.

The manifest records SHA-256 hashes for the shipped assets. The English-only data pack and original upstream source links must accompany redistributed builds.

The warm compact derivatives were made by Caro for Doug on 2026-10-16 with `compact_models.py`. They retain the northern_english_male model-card attribution and CC BY-SA 4.0 International terms; `compact-manifest.json` identifies the original hash, derivative hashes, methods and per-tensor numeric errors. The int8 candidate stores output-channel-scaled kernels (axis 1 for transposed convolutions, axis 0 otherwise); standard ONNX DequantizeLinear restores float32. The float16 candidate uses standard Cast nodes. These changes reduce transfer size; they do not establish identical perceptual quality or lower runtime memory.
